四、权限系统（真实）

工具审批流

  1. Bash 执行前 → 后端发 SSE permission 帧
  2. 前端显示 Approve / Deny 按钮
  3. 用户点击 allow → 继续执行
  4. 用户点击 deny → 终止执行

权限语义

术语含义
permission权限请求帧
approve批准
deny拒绝
reject拒绝（另一种表述）
