桌面端

macOS 与 Windows 应用。把你的电脑注册为设备后，任务可以直接在此电脑上运行。

桌面端是同一个 ClawsGO，多了一件事：把你的电脑注册为设备。之后任务可以选择在此电脑上运行，直接读写本地文件、运行本地命令。支持 macOS 与 Windows（x64）。

安装

下载

前往下载页面。Mac 按芯片选择 Apple 芯片版或 Intel 芯片版，打开 dmg，把 ClawsGO 拖进「应用程序」。Windows 运行下载的 exe，安装会自动完成并打开应用；如果系统提示「Windows 已保护你的电脑」，点「更多信息」再点「仍要运行」。

登录

桌面端不出现登录表单。点「在浏览器中登录」，在浏览器里登录中国站后自动回到应用。如果没有自动跳回，把浏览器页面上的登录代码粘贴到桌面端，代码 3 分钟内有效。

注册设备

登录后应用自动把此电脑注册为设备：设备名称取电脑名，工作目录为 ~/ClawsGO（任务的项目文件都放在这个目录下），完成后右下角提示「已连接此电脑」。设备凭据保存在此电脑的 ~/.clawsgo 目录，仅当前用户可读。

自动注册失败时会有提示，可在个人空间打开「主机」页，点左侧栏的「连接此电脑」手动注册。想换工作目录，先「断开此电脑」再手动注册并选目录。

注册后应用会在后台运行一个服务，状态显示在「主机」页里这台设备「设置」中的「本地连接」一行。服务未运行时旁边有「重新启动」按钮。

在此电脑上运行任务

桌面端里新任务默认在此电脑上运行，新建项目也默认在此电脑上；要换到云主机，在输入框上方的主机选择按钮里选。选过一次后会记住你的选择。本地设备上的任务与云主机任务的差别：

云主机本地设备
任务持续运行关电脑也不中断需要此电脑保持开机在线
桌面画面「主机」页签可以查看与接管不可远程预览
桌面自动化有无
文件菜单多出「在文件夹中显示」「用 VS Code 打开」

在协作团队里用此电脑

设备属于你的个人空间。要在协作团队里把任务交给此电脑运行，在该团队的「主机」页左侧栏点「添加本地设备」。

断开与换电脑

  • 断开此电脑：「主机」页里这台设备「设置」中的「断开此电脑」。设备凭据被吊销，从所有团队移除，其上的项目与任务一并移除，不可恢复。
  • 换电脑：新电脑上安装、登录即自动注册，旧设备可以之后再断开。断开过的电脑不会再自动注册，需要时手动连接。
  • 提示「此电脑上保存的设备配置已失效」：设备已在别处被移除或凭据被吊销，点「清除本地配置」后可以重新注册。
  • 提示「此电脑已在别处连接，本进程已退出」：同一台设备的凭据在另一处启动了，检查是否重复安装了应用。

自动更新

桌面端启动时检查更新，之后每 4 小时检查一次，后台下载。下载完成会在应用内提示，点「重启更新」立即安装。Mac 上不点也会在下次退出应用时自动安装；Windows 只在点了之后安装，约需两三分钟，期间显示安装窗口，完成后自动打开。后台服务随应用一起更新。

Windows 更新中途被打断（例如关机）后应用打不开时，从下载页面重新安装即可，登录和本机设置都会保留。

提示「桌面端版本过旧，请更新后重新启动」时，点应用内的「重启更新」；没有看到提示就退出并重新打开应用。

当服务端要求的最低版本高于当前版本时（协议升级或重要修复），应用会弹出不可关闭的更新提示并在后台下载，下载完成后点「重启更新」即可继续使用；也可以按上文链接手动下载安装。

修改密码

桌面端无法发送验证码。修改密码请到浏览器版的「设置 → 个人资料」里操作，桌面端设置里有「在浏览器中打开」按钮。
