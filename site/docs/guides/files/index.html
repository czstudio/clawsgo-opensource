文件面板与预览

浏览工作目录、在线预览与编辑文件、下载与上传。

文件面板在任务页右侧面板的「文件」页签里，显示当前任务所在项目的工作目录。工作目录在云主机上位于 /home/user/ClawsGO/<项目名>，上传的附件与 ClawsGO 产出的文件都在这里。

目录树

  • 单击文件打开预览；再次单击已打开的文件关闭它。
  • 单击目录展开或收起，子目录按需加载，每个目录最多显示 500 项。
  • 树顶部四个按钮作用于根目录：新建文件、新建文件夹、上传文件、刷新。
  • 文件名旁的字母是 Git 状态（M 修改、A 新增、U 未跟踪、D 删除、R 重命名、! 冲突），与 VS Code 相同。
  • 任务产出的科研绘图单独列在「科研绘图」组里，位于文件树上方。

右键文件或行尾的「更多」按钮打开同一份菜单：

项说明
查看 / 下载打开预览，或下载到本地
添加到对话把文件引用插入输入框，等于输入 @路径
复制路径 / 复制相对路径绝对路径或相对工作目录的路径
剪切 / 复制 / 粘贴在目录之间移动或复制
重命名 / 删除删除不可恢复

目录的菜单还有新建文件、新建文件夹、上传文件与打包下载。本地设备上另有「在文件夹中显示」与「用 VS Code 打开」。

node_modules、.git、.venv、__pycache__ 等目录不在树里显示。

预览

类型能做什么
代码与文本语法高亮，直接编辑；工作目录是 Git 仓库时，行号旁标出相对上次提交的改动（绿 = 新增、蓝 = 修改、红三角 = 删除）
Markdown打开即可编辑：标题、列表、表格、公式、图片与 Mermaid 代码块（流程图、时序图等）直接按排版显示，光标移到哪处就露出那处的 Markdown 写法；/ 插入块，划选文字出格式工具条；从网页、文档粘贴进来的格式自动转成 Markdown
PDF逐页渐进加载，翻页、跳页、缩放、适应宽度，可以选中复制文字
Officedocx、xlsx、pptx 打开即可编辑；旧式 doc、xls、ppt，带宏与模板格式（docm、xlsm、xlsb、potx 等），RTF 与 ODF 格式只读；Visio 图与 djvu、xps 扫描文档同样只读打开
图片缺省适应窗口；⌘ + 滚轮（Windows 上 Ctrl + 滚轮）或触控板捏合缩放，放大后拖动平移，双击在适应窗口与实际大小之间切换
SVG打开图形工作台：选择、矩形、椭圆、直线、文字工具，填充与描边；「源码」视图可编辑
表格csv、tsv 以表格显示，每格保留原文，不改写数据。双击格子即可编辑，只改这一格，文件其余部分不变；表格最多显示前 50 万行，完整内容在「源码」视图，可编辑
LaTeX.tex 打开 LaTeX 工作台：源码与 PDF 双栏，编译在云主机上完成
HTML在隔离沙箱中渲染，页面脚本照常运行；同目录的本地图片与样式不加载；「源码」视图可编辑
Mermaid.mmd、.mermaid 显示成图，缩放同图片；语法有误时提示无法渲染；「源码」视图可编辑
Jupyter 笔记本.ipynb 按单元显示：Markdown 排版、代码高亮、保存在文件里的输出（图、表、报错）；不运行代码；「源码」视图可编辑
分子结构pdb、cif、mol2、sdf、xyz 等三维显示，旋转缩放，切换卡通、球棍、分子表面；多模型逐个翻看，晶体 CIF 显示晶胞
密度图与格点数据电镜与晶体学密度图（mrc、map、ccp4，EMDB 的 .map.gz）、MTZ 与结构因子 CIF（按图系数算 2Fo-Fc / Fo-Fc）、密度服务器的 CIF / BCIF、APBS 的 dx、Gaussian 的 cube（电子密度与分子轨道）：三维等值面，拖滑杆调阈值（σ），切换网格与实心面
TIFF多页逐页翻看；16 位、浮点数据自动拉伸对比度；缩放同图片，光标处显示坐标与原始像素值
医学影像NIfTI、MGH / MGZ、NRRD、MHA、MRtrix MIF：多平面与三维渲染，换色表，4D 数据逐帧翻看；GIfTI、mz3、FreeSurfer 表面、纤维束（trk、tck、trx）与 VTK 网格三维显示，标出三角面数或纤维条数
3D 模型STL、OBJ、PLY、GLB、3MF、Collada（dae）、PCD：旋转缩放，PLY 与 PCD 点云按点显示；同目录的贴图文件不加载
音频与视频浏览器内播放

代码与文本格式之外，没见过的扩展名（如 .out、.dat）按内容判断：是文本就按代码打开。其他二进制文件显示「此文件暂不支持预览」，可以直接下载。DICOM、gltf、BAM、HDF5 等格式暂不在线打开。过大的文件显示「文件过大，无法预览」：代码、表格与 HTML 10 MB，Markdown 与 Mermaid 1 MB，SVG 4 MB，笔记本 30 MB，分子结构 50 MB，密度图 256 MB，TIFF 与 3D 模型 200 MB，医学影像 256 MB。

预览卡出现在对话与右侧面板之间。可以同时打开多个文件，各自一个页签。

编辑与保存

代码、文本与 Markdown 在预览里直接可编辑：停止输入 800 毫秒自动保存，⌘S（Windows 上 Ctrl+S）立即保存。右下角的状态显示「未保存 / 保存中 / 已保存 / 保存失败」。

Office 文档在内置编辑器里修改，⌘S 或编辑器自带的保存按钮立即写回云主机；关掉页签后编辑器会在几秒内再保存一次。保存状态看编辑器自己的状态栏。

人与 ClawsGO 同时改一个文件

没有锁，以最后一次保存为准。ClawsGO 正在写入的文件，等它写完再改。

自动预览

ClawsGO 交付文件时，可预览的类型会自动打开；它用工具写 Markdown 文件时，如果你正开着这份文件的预览，预览会实时跟着内容增长。自动打开预览时右侧面板同时收起给预览让位，关掉预览面板自动恢复。手机上不自动打开。

下载

  • 单个文件：菜单里的「下载」，或预览卡头部的下载按钮。Markdown 文件可以选 Markdown、Word、PDF 或纯文本格式。
  • 整个目录：目录菜单里的「下载」打包为 zip。目录里条目超过 500 项时会提示「目录过大，无法打包下载」，改为分目录下载。
  • 云主机休眠时，第一次下载需要先唤醒主机，按钮转圈可能持续几十秒。
  • 下载链接带签名，1 小时内有效。

上传

  • 面板内「上传文件」按钮上传到根目录，目录菜单里的「上传文件」上传到该目录。同名文件自动加后缀，不覆盖。
  • 拖到输入框或粘贴的文件作为任务附件，上传到工作目录下的 input 文件夹（没有会自动新建，并附带 .gitignore 与 .ignore 两个小文件：前者让附件不进入 Git 提交，后者让智能体仍能搜索到附件）。一条消息最多 10 个附件，单文件大小上限按方案，见方案与权益。

主机页签

右侧面板的「主机」页签是运行任务的这台主机：终端、云主机的桌面画面入口、CPU / 内存 / 磁盘用量，以及已接入的 SSH 服务器能否从这台主机连通。内核与架构、已安装的工具链、Python 包与 npm 全局包清单在「主机 → 环境」里。

磁盘用量接近上限时，在「主机 → 存储」里可以「清理缓存」，清理 pip、npm 等包管理器缓存，不影响项目文件与已安装的软件。各方案的磁盘配额见方案与权益。
