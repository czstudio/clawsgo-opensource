发出第一个任务

一句话描述任务，附上材料，ClawsGO 在云主机上开始工作。

写一条好的任务描述

不需要提示词技巧，像给一位新同事交代工作那样写就够了。三个要素：

  1. 目标：你要什么成果（一份综述、一张图、一段可运行代码）。
  2. 材料：附上文件，或给出数据来源。
  3. 约束：格式、篇幅、语言、截止时间。

正文上限 32,000 字。更长的内容作为附件上传。

附上材料

三种方式：点输入框「添加」菜单里的「上传文件」、把文件拖到输入框、直接粘贴（包括截图）。

  • 一次最多 10 个文件；单文件大小上限按方案，见方案与权益。
  • 选中即开始上传，上传中不能发送；失败的文件可以「重试」或「移除」。
  • 输入 @ 可以引用当前任务目录里已有的文件，或团队里之前的任务（智能体读取它截至发送时的对话，不复制它的文件），在云主机上还能点名预装的软件与工具、内置数据库（加号菜单里可按领域浏览）；输入 / 可以调用指令或技能。

发送前可以调什么

输入框里的设置按钮显示当前模型与推理强度，点开是五组选项：

选项内容
模式「单体」单个智能体端到端完成，适合目标明确的任务；「主从」主智能体规划，子智能体执行，适合多步骤任务，Plus 起；「集群」多个子智能体并行，为大规模调研与深度研究打造，算力消耗最高，Pro 起。已有任务里切换模式会弹确认：可用工具改变，上下文缓存重置一次
模型见选择模型
子智能体主从与集群模式下出现：主智能体派出的子智能体与集群成员使用的模型，默认 ClawsGO 1.5 Lithium，见选择模型
推理强度低 / 中 / 高 / 极高 / 极限。「极限」可能让模型过度思考，思考时间过长时改用「高」或「极高」
上下文256K、512K 或 1M，见选择模型

这五组设置都会记住：新任务沿用你上次的选择，已有任务沿用该任务上一轮的设置。

输入框上方先选主机，再选「选择项目」或「选择文件夹」（二选一，都不选则自动分配工作目录）。选项目会进入该项目的主页；选文件夹仅限本地设备。选定后悬停图标出现 ×，点它取消选择。项目内新任务的主机随项目固定。

Enter 发送，Shift+Enter 换行。有智能体回复后，发送键左侧的圆环显示当前任务的上下文占用，悬停可看已用与上限。

任务运行时你能做什么

每一步工具调用都实时出现在时间线上。运行中步骤展开显示；落定后收成一行「运行了 N 个步骤」，点开可以看每一步的输入与输出。模型的思考过程也在时间线上，收成一行「深度思考」，点开可以看思考内容（个别模型不输出思考内容，只显示用时）。发送键旁的上下文圆环随运行实时更新；接近上限时会自动压缩较早的对话。

交付物在哪里

成果文件都在右侧面板的「文件」页签里。ClawsGO 交付 Markdown、PDF、图片等文件时会自动打开预览，右侧面板同时收起给预览让位；关掉预览面板自动恢复。详见文件面板与预览。

之后

  • 直接发消息追加要求，同一个任务可以一直做下去。
  • 任务中断时输入框上方或回复末尾会出现原因卡，多数情况点「继续」即可恢复。对照表见原因卡对照。
  • 顶栏「更多操作」可以置顶、重命名、分享、隐藏或删除任务。侧栏里的任务行还能「转为项目」，把相关的后续任务放在同一个工作目录里。
