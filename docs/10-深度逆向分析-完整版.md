## 十一、线上 vs 本地 API 差异

### 11.1 响应格式差异

| 方面 | 线上 | 本地 | 修复建议 |
|------|------|------|----------|
| 成功响应 | `{ data: ..., error: null }` | `{ data: ... }` | 本地应添加 `error: null` |
| 错误响应 | `{ error: { code, message } }` | `{ error: { code, message } }` | 一致 |
| 状态码 | 200 | 200 | 一致 |

### 11.2 缺失命令

| 命令 | 线上状态 | 本地状态 | 优先级 |
|------|----------|----------|--------|
| `getNotifications` | 200 | 501 未实现 | 中 |
| `getLedger` | 200 | 501 未实现 | 中 |
| `getInviteCodes` | 200 | 501 未实现 | 中 |
| `getActivities` | 200 | 501 未实现 | 低 |
| `getSubagents` | 200 | 400 参数错误 | 高 |
| `getMcpServers` | 200 | 400 参数错误 | 高 |
| `getTeamMembers` | 200 | 400 参数错误 | 高 |

### 11.3 参数验证差异

线上部分命令不需要显式参数（有默认值），本地可能要求必填。需要检查：
- `getSubagents` - 可能需要 `projectId` 或 `scope`
- `getMcpServers` - 可能需要 `projectId`
- `getTeamMembers` - 可能需要 `teamId`
