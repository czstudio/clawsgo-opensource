### 5.2 任务创建与执行协议 [A]（全部实测）

```jsonc
POST /api/chat_session/create  {"query": "<用户输入+模式要求后缀>"}
  → {result:{id:"<32hex>", title, titleType:"user"}}
POST /api/task/create_task {
  "agentName": "Idea Agent",            // 模式对应 agent
  "chatSessionId": "<32hex>",
  "query": "@Idea Spark <query>",        // @模式名 前缀
  "queryContent": "<query>",
  "enableGpu": false,                    // CPU/GPU 切换（UI 实测）
  "enableBrainstorming": false,
  "questionMode": "task",               // task | discuss
  "fileIds": [],
  "modelOverride": "novix_proxy__gpt-6.1-sol"   // ★ 真实底层模型
}
  → {result:{id:"<taskId 数字>", status:"processing"}}
GET /api/task/get_task?taskId=<id>      // ~1-2s 轮询（非 SSE！）
  steps[].content = {"type":"trajectory","content":"[{role,content|tool_calls},…]"}
POST /api/chat_session/workspace/subtree // 工作区树（writing_outputs/ + search_results/）
```

- 文件工作区内部路径泄漏：`nova_agent_v1/user_data/session_<id>/workspace/project|search_results`
- **模型供给实锤**：`modelOverride: "novix_proxy__gpt-6.1-sol"`（Idea Spark 与 Method Design 同值）——novix 自有模式跑在 gpt-6.1-sol 代理上
