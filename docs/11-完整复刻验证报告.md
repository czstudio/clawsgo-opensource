### 2.3 传输通道

生产环境使用 4 种传输方式：

1. **JSON RPC**: `POST /api/<command>` → `{data, error: null}`
2. **Binary**: `_e` 端点（文件下载）
3. **Upload**: `ye(cmd, query, raw)` — 参数在 query string
4. **Form**: `ve(cmd, raw)` — multipart/form-data

