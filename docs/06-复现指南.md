## 2. 这个仓库是怎么造出来的

全部脚本在 `tools/`，按顺序可重跑。需要 Python 3.13+（仅标准库，**不需要装任何包**）。

### Step 1 · 镜像营销站

```bash
python tools/mirror_marketing.py
```

- 抓 5 个路由的 HTML
- 正则解析出各页引用的 `_next` chunk 与图片
- 下载全部资源 + 已知固定路径（favicon / og / robots / sitemap / 招聘海报）
- 结果：5 个 HTML + 29 个资源

**要点**：营销站是 Next.js 预渲染，HTML 里已含完整内容与 RSC flight 数据（首页 741 KB）。**只要 CSS/JS chunk 齐，本地就能完全还原渲染和动画。**

### Step 2 · 拉取应用端入口

```bash
python tools/mirror.py
```

从 `app.clawsgo.cn/index.html` 提取 42 个 `/assets/` 引用并下载。

### Step 3 · 递归展开应用依赖图

```bash
python tools/crawl_app.py
```

以入口为种子，反复解析每个 chunk 里的静态/动态 import 引用，**递归直到收敛**。

结果：601 个文件 / 20 MB。

**踩坑记录：**

- 不要在 bash 里写 `while read f; do curl ...; done` —— **curl 会吃掉循环的 stdin**，导致只有第一条能下载，后续 URL 为空。要么用 Python 下载器，要么给 curl 加 `</dev/null`。
- 首次运行可能被超时中断（SIGTERM），但**已下载的文件会保留**，重跑会从断点继续（脚本按文件存在性跳过）。

### Step 4 · 静态分析 / 还原契约

```bash
python tools/analyze.py        # 特征扫描：库、动画、主机、i18n
python tools/api_trace.py      # API 命令名追踪
python tools/emit_contract.py  # 产出 contracts/*.json
```

**API 命令名的追踪方法**（这是整个逆向里最关键的一步）：

1. 解析 `api-pyi_9PXn.js` 的 `export{a as A, h as C, ...}`，建立「本地名 → 导出名」映射
2. 定位承载 `POST /api/${cmd}` 的包装函数（`Q` / `_e` / `ve` / `ge`）
3. 找出它们的导出别名（`s` / `c` / `u` / `o` / `l`）
4. 在每个 chunk 里解析 `import{...}from"./api-pyi_9PXn.js"`，把导出别名映射到该 chunk 内的局部别名
5. 搜索 `局部别名("命令名"` 的调用点

因为代码被 minify 过，**只有这一条路径能得到准确命令名**——直接正则扫字符串会混入大量 DOM 事件名（`mousemove`、`touchstart`）和 MIME 类型（`text/plain`）。

### Step 5 · 组装与改写

```bash
python tools/assemble.py
```

- 营销站页面 → 目录路由
- `https://app.clawsgo.cn` → `http://localhost:5181`
- `api-pyi_9PXn.js` 里的 `API_BASE` 常量 → `""`（同源）

## 4. 后端复刻：为什么是「按契约重写」

bundle 里能拿到的只有**调用点**：传什么参数、怎么解构返回值。服务端实现拿不到。
所以后端的做法不是「还原」，而是**把每个调用点当成验收标准，实现到前端真能用为止**。

闭环是三步：

1. 读调用点 → 得到形状（`docs/07-数据形状.md` 是这一步的产物）
2. 按形状实现（`server/`，211 条命令）
3. 写成断言跑起来（`tools/e2e.mjs`，219 项）

只有第 3 步全绿，前两步才算成立。这一轮真正被断言逼出来的问题：

| 症状 | 根因 |
|---|---|
| 文件直链拼出 `undefined/api/...` | 前端解构 `let {link:n} = await api('createFileLink',...)`，**少写了一层 `link` 包装** |
| 下载按钮无反应 | 前端拼 `` `${url}&download=1` ``，所以 `url` 里**必须已经带 `?`** |
| Office 面板必崩 | `session` 必须是 ONLYOFFICE `{serverUrl, config}`；React key 还依赖 `config.editorConfig.mode` + `config.document.key` |
| 签名直链 401 | `<img>` / `<iframe>` / DocumentServer 带不上 Authorization 头，token 本身就是凭证 |
| 新建文件夹 409 | 前端按钮无冲突提示，语义应是 `mkdir -p`（幂等） |
| 工作区「看似空」 | Glob 的 `?` → `[^/]` 替换顺序错，正则自毁 |
| 刚登录就 401 | 每请求都 `load()` 磁盘快照，覆盖了「刚写内存、尚未落盘」的数据 |
| 迁移进度永远停在旧值 | 状态回落用了合成空壳，而不是**最近一次**作业的真实状态 |
| 缺一个 chunk 却拿到 HTML | SPA 回落把不存在的静态资源也吞成 `index.html`，浏览器报 `Unexpected token '<'` |

### 与真实 LLM 对接

```bash
CLAWSGO_LLM_BASE_URL=https://... CLAWSGO_LLM_API_KEY=sk-... CLAWSGO_LLM_MODEL=... \
  node server/serve.mjs
```

## 5. 对接你自己的真实后端

如果后端是你自己的，把复刻层摘掉即可：

```js
// app/assets/api-pyi_9PXn.js
const W = "https://your-api.example.com";
```

并让静态服务不再拦截 `/api/`：

```js
// server/serve.mjs —— 删掉或注释这段
if (p.startsWith('/api/')) {
  return await handleApiRequest(req, res, url);
}
```

或者保留 `serve.mjs` 只做静态托管（它已经能正确处理 SPA fallback）。

跨域时你的后端需要放行这几个头：

```
Access-Control-Allow-Origin:  <你的站点>
Access-Control-Allow-Headers: Content-Type, Authorization
Access-Control-Expose-Headers: set-auth-token, content-disposition, content-type
```

`set-auth-token` **必须 expose**，否则前端读不到 token 轮换。`content-disposition` 也一样，前端靠它判断响应是文件还是错误 JSON。

## 6. 重建为可维护源码工程

现在手里的是 **minify 后的产物**，能跑但不适合长期维护。要变回可读源码有两条路：

### 路线 A：去混淆（工作量大，结果近似）

1. **格式化**：`npx js-beautify -o out.js in.js`，或 prettier
2. **还原符号**：用 `jsnice` / `deobfuscator.io` 做局部重命名（变量名如 `e,t,n,r` 无法还原成有意义的语义名）
3. **拆分模块**：按 chunk 边界还原文件划分（路由 chunk 天然对应页面组件）
4. **重建 JSX**：产物里是 `jsx(div, {className:...})` 调用，需反向转成 JSX 语法
5. **重建样式**：`index-Bk3BrKyc.css` 是 Tailwind v4 编译产物，**无法反编译回 `className` 用法**，只能逐条对照

> 老实说：完整重建到「可维护」的投入，远大于**直接用你自己的源码仓库**。如果原始仓库还在（GitHub / 服务器 / 本地），用那个。

### 路线 B：以契约为准重写（推荐）

产物已经给了你三样重写所需的全部信息：

- **路由结构** → `contracts/routes.json`
- **接口契约** → `contracts/commands.json` + `docs/03-API契约.md`
- **视觉与动效** → `docs/05-动画与动效.md` + 完整 CSS

用 TanStack Router + TanStack Query + Base UI + Tailwind v4 + Framer Motion 起一个空工程，照契约填页面即可。前端可以做到**行为一致、外观一致**，而代码是你自己的。

## 7. 常见问题

**Q：应用页面白屏？**

检查复刻后端是否在跑（`curl -X POST -d '{"data":{}}' http://localhost:5181/api/getProfile`）。应用启动时会调 `getProfile` 之类接口，全部失败会触发重定向循环。

**Q：登录后一直跳回 `/login`？**

说明响应里出现了 `UNAUTHORIZED`。只在「token 不在内存表」时才会走到这条路；如果重启过服务，**旧 token 会失效**——清掉 `localStorage` 里的 token 再登录。想彻底对齐状态就 `curl -X POST http://127.0.0.1:5181/__reset`。

**Q：阿里云验证码报错？**

`o.alicdn.com` 的外部脚本。离线或被墙时静默失败，不影响其他功能。要彻底去干净，删掉 `app/index.html` 里的那两行 `<script>`。

**Q：某些页面报 chunk 404？**

懒加载 chunk 是按路由触发的。`crawl_app.py` 已经递归到收敛（601 个），正常不会缺。若确实缺，从报错信息里拿到文件名手动补：

```bash
curl -o app/assets/<name> https://app.clawsgo.cn/assets/<name>
```

**Q：`monaco` / `shiki` 加载慢？**

前者 2.65 MB，后者按语言分包。本地无 CDN 加速，首次加载慢是正常的。
