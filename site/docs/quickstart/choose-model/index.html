ClawsGO 文档

选择模型

ClawsGO 1.5 三个档位，加上菜单里的第三方旗舰模型。参考倍率标在每个模型旁边。

模型在输入框设置菜单的「模型」子菜单里切换。每个模型行尾标着参考倍率：该模型在典型任务上的消耗相对 ClawsGO 1.5 Silicon（x1.0）的大致比价。实际扣除按各模型的输入、输出与缓存单价分别计算，见算力与计价。

ClawsGO 1.5

ClawsGO 1.5 是 ClawsGO 的自有模型系列，基于顶级开源模型，针对 ClawsGO Science Harness 后训练与微调。三个档位对应三种取舍：

档位定位参考倍率可用方案
Lithium轻量、快速、低消耗x0.5Free 起
Silicon能力与消耗的平衡点x1.0Plus 起
Titanium性能优先，为复杂科研打造x1.5Pro 起

新账号默认使用 Lithium。

第三方模型

菜单同时提供 Anthropic 与 OpenAI 的模型，ClawsGO 的研究框架不变，只替换底层模型：

模型定位参考倍率可用方案
Claude Sonnet 5.5最新主力模型，擅长编码与智能体任务x1.0Plus 起
Claude Opus 5.5最新旗舰模型，擅长深度推理与复杂任务x2.0Pro 起
GPT 5.6 Terra最新中型模型，速度与能力兼顾x1.0Plus 起
GPT 6.1 Sol最新主力模型，擅长编码、数据分析与复杂推理x1.0Pro 起
GPT 6 Astra最新旗舰模型，为高难度推理与科研打造x4.0Pro 起
Claude Fable 5.1最新 Mythos 级模型，为最难的科研问题打造x10.0Ultra 起

菜单尾部「更多 → 查看全部模型」打开搜索弹窗，按厂商分组，里面还有上一代型号。切换到 Claude Fable 系列前会弹确认，标出它相对 Claude Opus 5.5 的消耗倍数。

方案未包含的模型显示为灰色，点击会打开订阅区。各方案的模型范围见方案与权益。

怎么选

  • 日常问答、格式整理、小段代码：Lithium。
  • 多文献综述、数据分析、论文起草：Silicon 或 Claude Sonnet 5.5。
  • 长程复杂研究、需要反复自检的推导：Titanium、Claude Opus 5.5 或 GPT 6 Astra。
  • 最难的问题：Claude Fable 5.1。

任务中切换

新任务页切换模型没有副作用。在已有任务里切换会弹确认：切换会重置上下文缓存，下一轮消耗更高，之后恢复正常。切换只影响之后的回合，正在运行的回合不受影响。

模型拒绝处理某段内容时，换一个模型，再回复「继续」。第三方模型的拒绝由其厂商的安全策略判定，ClawsGO 无法干预。

子智能体模型

设置菜单「子智能体」子菜单决定主智能体派出的子智能体用哪个模型，智能体集群的成员也用它。只在主从与集群模式下出现，默认 ClawsGO 1.5 Lithium，也可以选「跟随主模型」。

  • 所有子智能体统一使用这一个模型，由你选定，主智能体自己改不了。
  • 只影响子智能体：主对话、网页抓取后的摘要和上下文压缩仍用主模型。
  • 可选范围、灰色锁定与 Claude Fable 系列的确认，都和「模型」子菜单一致。
  • 在已有任务里切换子智能体模型不会破坏主对话的上下文缓存，所以不弹确认。

子智能体的调用按子智能体模型的单价计费。常见用法：主模型用强档负责规划与把关，子智能体用 Lithium 做大量检索和读文件；或者反过来，让更强的模型去做关键的审阅。

上下文档位

设置菜单「上下文」子菜单里有三档：

  • 256K：标准档，适合绝大多数任务。接近上限时自动压缩较早内容继续运行。
  • 512K：为长文献与多步骤任务留出更多空间。不另收功能费，但每轮输入随之增加，算力消耗随之上升。Plus 起可用。
  • 1M：容纳更多文献、数据与代码，细节保留更完整。每轮输入更多，算力消耗显著上升。Pro 起可用。

新任务沿用你上次选的档位，方案不含该档时从 256K 起步。选了 512K 或 1M 的任务会在设置按钮上常驻显示档位。

推理强度

五档：低、中、高、极高、极限。默认「高」。三种模式都按所选强度运行。集群模式下集群成员默认也用这一档，主智能体编排时可以给个别步骤单独调高或调低。
