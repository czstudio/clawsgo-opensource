# 05 · 动画与动效细节

所有关键帧与参数**原样保留在产物里**，本文件把它们提取出来集中说明。

## 1. 营销站关键帧

### `0gp6uf8xiuzua.css` — 主样式，14 个关键帧

```css
/* 首屏标题入场 */
@keyframes hero-drop {
  0% { opacity: 0; filter: blur(10px); transform: translateZ(300px) translate(50px); }
}

/* 次级元素入场 */
@keyframes hero-rise {
  0% { opacity: 0; filter: blur(10px); transform: translateY(20%); }
}

/* 机构 Logo 无缝走马灯 */
@keyframes marquee {
  to { transform: translate(-50%); }
}
```

**手法解读：**

- `hero-drop` 用了 `translateZ(300px)` —— **3D 纵深推入**，配合 `blur(10px)` 做「从远处虚化处落下」的观感。这比常规的 `translateY` 高级一档，是首屏最贵的一个动作。
- `hero-rise` 是标准 `translateY(20%) + blur` 上浮。两个动画共享 `blur(10px) → 0` 的虚化收敛特征，视觉语言统一。
- 两份关键帧**都只定义 `0%`**，终点由元素的默认态隐式接管 —— 这是 Tailwind + `animate-in` 体系的标准写法，好处是元素静态样式即终态，无 JS 也能正确显示。
- `marquee` 用 `translate(-50%)` 实现无缝循环，前提是**列表内容必须复制一份**（DOM 里渲染两组 Logo），滚动一半时视觉回到起点。

其余共用关键帧（Tailwind 体系）：

```css
@keyframes enter { 0% { opacity: var(--tw-enter-opacity,1);
  transform: translate3d(var(--tw-enter-translate-x,0), var(--tw-enter-translate-y,0), 0)
             scale3d(var(--tw-enter-scale,1), var(--tw-enter-scale,1), var(--tw-enter-scale,1))
             rotate(var(--tw-enter-rotate,0));
  filter: blur(var(--tw-enter-blur,0)); } }

@keyframes exit { to { /* 同构，变量换成了 --tw-exit-* */ } }

@keyframes accordion-down { 0% { height: 0 } to { height: var(--radix-accordion-content-height, var(--accordion-panel-height, auto)) } }
@keyframes accordion-up   { /* 反向 */ }
@keyframes spin       { to { transform: rotate(360deg) } }
@keyframes pulse      { /* 通用呼吸 */ }
@keyframes caret-blink { 0%,70%,to { opacity:1 } 20%,50% { opacity:0 } }
@keyframes tw-shimmer  { 0% { background-position: 100% 0 } to { background-position: 0 0 } }
```

`caret-blink` 用 `0%,70% / 20%,50%` 描述一个**不对称的闪烁节律**（亮 70%、暗 30%），比 `steps()` 的机械感更接近真实光标。

### `1o90qstsyjm41.css` — 时间线演示动画，9 个关键帧（`ilo-` 前缀）

这是首页最复杂的一段 —— 「一夜之间」的 agent 执行过程逐条入场：

```css
@keyframes ilo-in     { 0% { opacity: 0 } }                                              /* 容器淡入 */
@keyframes ilo-out    { 0% { opacity: 1 } to { opacity: 0 } }                            /* 容器淡出 */

/* 单条执行记录（"Search PubMed — 428 records  6m"） */
@keyframes ilo-item   { 0% { opacity: 0; filter: blur(4px); transform: translateY(8px) } }

/* 小圆点 / 标记 */
@keyframes ilo-pop    { 0% { opacity: 0; transform: scale(.4) } }

/* 卡片（"Breaking the question into a protocol"） */
@keyframes ilo-rise   { 0% { opacity: 0; transform: translateY(14px) scale(.97) } }

/* 时间线自身向上滚动 */
@keyframes ilo-scroll { 0% { transform: translateY(0) } }

@keyframes ilo-spin   { to { transform: rotate(360deg) } }

/* 光标闪烁（与 caret-blink 不同的节律：亮 45%） */
@keyframes ilo-blink  { 0%,45% { opacity: 1 } 46%,to { opacity: 0 } }

/* 新条目入场时的高光扫过 */
@keyframes ilo-flash  {
  0%   { background-color: #ffffff12; background-color: lab(100% 0 0/.07) }
  to   { background-color: #0000 }
}
```

**这套动画的编排逻辑：**

| 动画 | 层级 | 位移 | 模糊 | 缩放 |
|---|---|---|---|---|
| `ilo-item` | 单条记录 | `translateY(8px)` | `blur(4px)` | — |
| `ilo-rise` | 卡片 | `translateY(14px)` | — | `.97` |
| `ilo-pop` | 圆点 | — | — | `.4` |
| `ilo-flash` | 高光 | — | — | — |

位移量与元素体量正相关（圆点 0 → 记录 8px → 卡片 14px），模糊只用在最轻的记录行上——**轻元素用模糊、重元素用位移**，避免大块模糊造成的性能抖动。

`ilo-flash` 里写了两次 `background-color`，第二次用 `lab(100% 0 0/.07)` —— 这是**渐进增强**写法：支持 `lab()` 的浏览器用感知均匀的色值，不支持的用 `#ffffff12` 兜底。

## 2. 应用端动画

### Framer Motion

从 `login-JE4ErYsw.js` 直接读到参数：

```js
const Vr = { type: 'spring', bounce: 0, duration: 0.4 };

// 登录页「验证码 / 密码」tab 切换的高亮胶囊
<motion.span
  layoutId="login-tab-pill"
  className="absolute inset-0 rounded-2xl bg-background dark:bg-input/30"
  transition={Vr}
/>
```

**`layoutId` + `spring{bounce:0, duration:0.4}` 是全文出现频率最高的动画签名**（bundle 中 `layoutId` 出现 21 次）。

实现效果：tab 切换时高亮块**从旧位置滑动到新位置**，而不是各自淡入淡出。`bounce: 0` 表示无回弹——克制、准确，符合科研工具的调性。0.4s 是「能感知到但不等」的时长。

同类共享的 `layoutId` 还有 `login-tab-pill` 这一类命名约定，说明全局有统一的动效 token。

### 全站缓动曲线

```css
cubic-bezier(0.45, 0, 0.4, 1)     /* 营销站主缓动 —— 近似 easeInOutQuart 的强收尾 */
cubic-bezier(0.22, 1, 0.36, 1)    /* easeOutQuint —— 快出慢收，用于入场 */
cubic-bezier(0.4, 0, 0.2, 1)      /* Material 标准缓动，用于通用过渡 */
```

三者分工明确：`0.22,1,0.36,1` 用于**入场**（启动快、收尾稳），`0.4,0,0.2,1` 用于**状态切换**，`0.45,0,0.4,1` 用于**营销站的展示型动画**。

### View Transitions API

`29e9lx6xn_hg_.js` 中出现 `startViewTransition`（全站 5 处）。用于页面/路由切换时的原生跨文档过渡。这是**渐进增强**——不支持的浏览器直接跳过，无副作用。

### Web Animations API

全站 25 处 `.animate()` / `new Animation()`。主要用于**命令式一次性动画**（如新消息插入、面板展开），避免为单次动效引入 React 状态。

### CSS 关键帧（应用端）

与营销站共用 Tailwind 体系，另有：

```css
@keyframes scroll-fade-reveal-s { 0% { --scroll-fade-s: 0px }
                                  to { --scroll-fade-s: var(--_scroll-fade-size-s,
                                        var(--scroll-fade-size, min(12%, calc(var(--spacing) * 10)))) } }
@keyframes scroll-fade-reveal-e { 0% { --scroll-fade-e: <size> } to { --scroll-fade-e: 0px } }
@keyframes scroll-fade-reveal-b { 0% { --scroll-fade-b: <size> } to { --scroll-fade-b: 0px } }
```

这三个是**滚动容器的边缘渐隐遮罩**（`s`tart / `e`nd / `b`oth），通过动画化 CSS 自定义属性来驱动 `mask-image` 的渐变距离。用 `min(12%, calc(var(--spacing) * 10))` 让遮罩高度随容器尺寸自适应——小容器不要吃掉太多内容。

## 3. 动效设计原则（从参数反推）

把上面所有证据收拢，这套产品的动效有明确的取舍：

1. **克制优先。** `spring{bounce:0}`、无弹跳、无夸张缩放（最大 `.97`）。科研工具的调性不允许花哨。
2. **模糊只给轻元素。** `blur` 出现在 hero 标题（首屏，一次性）、时间线单条记录（数量多但元素轻）。重卡片一律用位移。
3. **位移量与体量正相关。** 4px → 8px → 14px → 20%，元素越大走得越远，视觉速度才一致。
4. **时长集中在 0.4s。** tab 胶囊 0.4s；关键帧只定 0% 由静态态接管，实际时长由 Tailwind 的 `animation-duration` 统一给。
5. **渐进增强不降级。** `lab()` 色值、`View Transitions`、CSS 变量动画——全部是「支持则更好，不支持不影响功能」。
6. **3D 纵深只用在首屏。** `translateZ(300px)` 全站仅 hero 一处，稀缺性保证了它的冲击力。
