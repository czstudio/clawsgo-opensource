界面导览

左侧栏、新任务页、任务页与右侧面板，以及几个常用弹窗。

左侧栏

自上而下：

  • 团队卡片：当前所在团队，点开可以切换团队或「管理团队」。
  • 功能组：新任务、图像生成、主机、智能体、团队与订阅、技能市场、搜索。
  • 三个任务区：「置顶任务」「项目」「任务」。点区标题可以整组收起。置顶区与项目区尾部有「加载更多」按钮；任务区滚动到底自动加载。三个区都可以拖动排序，顺序全队共享；新任务出现在最上面，之后停在你排好的位置，发消息不会把它顶上来。
  • 筛选：协作团队的任务区有筛选按钮，「全队资源」看全队，「只看我的」只看自己创建的。个人空间没有这个按钮。
  • 底部：邀请卡与你的头像。点头像打开用户菜单：选择方案、设置、工单、主题、语言、退出登录。

⌘B（Windows 上 Ctrl+B）开合侧栏。

新任务页

点「新任务」进入。上方是问候语、一行自述与三张起点卡，输入框在页面底部，输入框上方可以选主机，再选项目或文件夹（二选一）。点卡片进入对应页面，「全部起点」返回，已输入的文字不受影响：

  • 研究：研究类案例，点开看交付物，「用这个例子」把任务描述填进输入框。
  • 指南：聚合检索、自有模型、图像生成与推广大使的说明。
  • 接力：继续已有的项目。选本地文件夹（需要桌面端，选定后主机切到此电脑）、打开「智能体」弹窗添加 SSH 服务器，或把克隆 Git 仓库的任务描述填进输入框。

在项目里点「新任务」时不出起点卡，页面只有问候语、所属项目与输入框。

任务页

  • 顶栏：打开过的任务成为页签，可以拖动换位，右键关闭。右缘的按钮开合右侧面板。
  • 中间：对话与时间线。用鼠标或触控板时，对话左缘的一列短横线是目录，每条对应一轮问答，鼠标在上面移动时右侧显示这一轮的提问与回复开头，点卡片跳到这一轮；目录只列已经加载的消息，往上滚加载更早的消息后会跟着变长。打开文件时，预览卡出现在对话与右侧面板之间。
  • 右侧面板四个页签：
页签内容
总览任务计划的步骤进度、本任务交付的文件，以及本任务调度过的子智能体
文件工作目录的文件树，点文件打开预览，见文件面板与预览
Git布局与 VS Code 的源代码管理一致：当前分支与待推送 / 待拉取数、工作目录的更改（列表或树形）、提交图表（点提交展开改动的文件）。只读，提交、推送等操作交给智能体
主机运行任务的这台主机：终端、桌面画面入口、CPU / 内存 / 磁盘用量、已接入的 SSH 服务器

进入任务默认停在「总览」。面板宽度可以拖动调整。

项目

项目在选定的主机上有自己的工作目录，相关任务都在这个目录里进行，后一个任务可以直接用前一个任务的产物。

  • 新建：侧栏「项目」区的「新建项目」，填名称、所在主机、工作目录。
  • 转为项目：侧栏里独立任务的菜单有「转为项目」，任务变成项目，之后可以在其中继续新建任务。这个操作不可逆。
  • 在项目里开任务：项目行的铅笔按钮。项目内任务的主机与目录随项目固定。

搜索

侧栏「搜索」按标题搜索团队内的任务与项目。没有输入时是浏览面板，按置顶、项目、任务三区列出。左栏可以只看置顶任务、项目或任务。

常用弹窗

设置（用户菜单 → 设置）五个分区：

分区内容
通用主题、语言、系统通知、完成提示音
个人资料头像、昵称、手机号、密码、退出所有设备
邀请邀请码与邀请统计
工单提交与查看工单，有新回复时头像上有红点
联系我们支持邮箱

团队与订阅（侧栏「团队与订阅」或团队卡片「管理团队」）：

分组分区
团队通用、成员
资源已隐藏，这里恢复被隐藏的任务与项目
计费订阅、用量、订单、发票

智能体（侧栏「智能体」）：身份组有「指令」（所选主机的全局 AGENTS.md），能力组有「技能」「SSH 服务器」。项目自己的指令与记忆在侧栏项目菜单的「项目设置」里。

技能市场（侧栏「技能市场」）：按领域与工作环节浏览官方技能，装上后对全队所有主机的任务生效。任务里智能体按技能描述自行调用，也可以在输入框键入 / 点名。

主机（侧栏「主机」）：左侧栏换成团队的云主机与本地设备两组，组内有「创建云主机」「连接此电脑」等入口；点「返回」回到任务列表。选中一台主机后，第一栏上半是这台主机的概览、存储（云主机）、环境、桌面（云主机）、终端与设置，下半是它上面的项目；点项目逐层浏览工作目录，右侧预览选中的文件。云主机休眠时浏览项目列表不会唤醒它，打开项目、存储、环境或桌面时才唤醒。
