## 布局层

TanStack Router 的路径less 布局路由，从 `_app/admin/users` 这类完整路径可以确认：

| 段 | 作用 |
|---|---|
| `__root__` | 根：QueryClientProvider、Toast、i18n、主题 |
| `_app` | 登录后外壳：侧栏导航 + 顶栏 + 工作区上下文 |
| `_shell` | 独立壳：用于登录、重置密码、支付回跳等不显示侧栏的页面 |

## UI 文案（Paraglide i18n，1012 个键）

文案键**每个键一个独立 chunk**，例如：

```
admin_col_balance      admin_col_contact      admin_col_invited_revenue
admin_col_paid         admin_col_team         admin_empty_hint
admin_filter_all_status admin_hosts_title     admin_load_failed
admin_nav_overview     admin_section_total    admin_unnamed_user
billing_invoice_reversed
```

这套按 key 切分的方式让首屏只加载用到的文案，代价是 chunk 数量爆炸——这也是 601 个文件里绝大多数都是小文件的原因。

站点支持中英双语（登录页可见成对定义）：

```js
Ne = ((e={}, t={}) => (t.locale ?? currentLocale()) === 'en' ? `Log in or sign up` : `注册/登录`)
```

## 超时 / 缓存策略

```js
new QueryClient({
  defaultOptions: {
    queries: { staleTime: 30_000, refetchOnWindowFocus: false },
  },
})
```

- `staleTime` 30 秒：避免切换页面时重复拉取
- **关闭窗口聚焦重取**：因为对话页有 SSE 长连，重取会打断流式状态
