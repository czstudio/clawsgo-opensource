# 数据形状速查（字段 / 单位 / 分页）

本文件只讲一件事：**每个命令吐出来的 JSON 到底长什么样**，以及字段的单位。
写前端或排查「字段是 undefined」时先看这里。

所有结论都来自反解 `app/assets/*.js` 里真实的解构代码，不是推测——
每一条后面都标了证据文件与片段，方便你自己复核。

---

## 1. 信封与传输

```
POST /api/<command>            Content-Type: application/json
body:  { "data": { ...参数 } }
ok:    { "data": { ...结果 } }             ← 结果永远在 .data 里
err:   { "error": { "code": "...", "message": "..." } }
```

- 每个业务响应都带 `set-auth-token`，前端 `X(res)` 会把它写回 localStorage（token 轮换）。
- `error.code` 前端有分支判断：`UNAUTHORIZED` / `NOT_FOUND` / `CONFLICT` /
  `FORBIDDEN` / `BAD_REQUEST` / `LINK_EXPIRED` / `IS_DIRECTORY`。
  `UNAUTHORIZED` 会被拦截器转成跳 `/login?redirect=...`。
- 证据：`app/assets/api-pyi_9PXn.js`
  `fetch(`${W}/api/${e}`, {method:'POST', headers:Y(), body:JSON.stringify({data:t})})`，
  `W=""`（同源），`if(r.error) throw new K(r.error.code, r.error.message); return r.data`

### 客户端四条通道

| 前端函数 | 用途 | 请求 | 响应判定 |
| --- | --- | --- | --- |
| `Q(cmd, payload)` | 普通 JSON | JSON 信封 | 读 `.data` |
| `_e(cmd, payload)` | 下载 | JSON 信封 | **看 `content-disposition` 头**，有则当 Blob |
| `ye(cmd, query, body)` | 上传 | **参数在 query string**，body 是原始字节 | JSON |
| `ve(cmd, raw)` | 上传 | FormData | JSON |

> 踩坑点：`ye` 的参数在 query 而不是 body。服务端必须把 query 合并进 payload，
> 否则「缺少参数 conversationId」。见 `server/api/index.mjs` 的 `payloadFrom(req, buf, url)`。

## 2. 分页

前端分页工厂（`_shell-CSlH67JO.js` 一类）统一按这个约定：

- 请求带 `limit = pageSize + 1`（多要一条用来判断「还有没有下一页」）
- `getNextPageParam` 用**累计长度**，不是页码
- 因此服务端只需要老实支持 `limit` / `offset`，**不需要返回 total**

已知 pageSize：会话列表 `bn = 50`，项目列表 `H = 5`，报表类 20。

**反转分页**：`getMessages` 的 `offset` 是「从最新往回数」，
所以**第 0 页是最新消息**，`getNextPageParam` 也用累计条数递增。
证据：`AdminUserDetailDialog-D3FjH6JN.js`
`getNextPageParam:(e,t)=>e.length>=_a?t.reduce((e,t)=>e+t.length,0):void 0`

## 3. 消息与 parts

`getMessages` → `{ messages }`，每条：

```jsonc
{
  "id": "...", "conversationId": "...", "role": "user|assistant",
  "parts": [ /* 见下 */ ],
  "createdAt": "...",
  "streamId": null        // 生成中才有值；完成后会被清空，前端据此判断「还在流式」
}
```

`parts[].type` 的取值与各自字段：

| type | 说明 | 关键字段 |
| --- | --- | --- |
| `text` | 正文 | `text` |
| `reasoning` | 思考过程 | `text` |
| `tool` | 工具调用 | `toolName`, `state`(`input-available`\|`output-available`), `input`, `output`, `durationMs`, `permission` |
| `block` | 结构化块 | `block` |
| `compaction` | 上下文压缩 | `summary` |
| `file` | 产出文件 | `path`, `size` |
| `resume` | 断点续跑 | `cursor` |
| `structured` | 结构化结果 | `data` |

> 断言工具引用的坑：`tool` part 在**执行前**就已经以 `state:'input-available'` 出现，
> 此时 `output` 是 `undefined`。要判断「执行完了」必须同时看 `state === 'output-available'`。

## 4. SSE 帧

两条通道，都是 POST + 长连接：

- `POST /api/subscribeEvents`，body `{}` —— 对话事件
- `POST /api/watchConversationFiles`，body `{data:{conversationId}}` —— 文件变更（真 fs.watch）

帧类型（`type` 字段）：

```
channel-ack       连上即发，带 running 数量
part-delta        增量文本 { partIndex, delta }
part              完整 part 落定
track-part        子智能体内部步骤（带 agentId）
permission        请求审批 { requestId, toolName, input }
permission-answered  审批结果回执
title-updated     首轮自动生成标题
done              运行结束，带 usage { input, output }
error
```

审批回执：`answerPermission { conversationId, requestId, behavior: 'allow'|'deny' }`。

文件通道帧：`ready` / `change`（`events[].path`，带 `truncated`）/ `error` / `ping` / `dormant`。
`.git/` 下的变化会被前端主动忽略。

## 5. 文件与直链

### createFileLink / adminCreateFileLink

```jsonc
{ "link": { "url": "/api/downloadConversationFile?token=...", "token": "...", "expiresAt": "..." } }
```

- **必须有外层 `link`**。前端是 `let {link:n} = await api('createFileLink',...)` 然后 `` `${base}${n.url}` ``，
  少这层会拼出 `undefined/api/...`。
- 证据：`ModelIcon-ACnHMn8i.js`
  `async function ar(e,t){let{link:n}=await o('createFileLink',{conversationId:e,path:t});return `${ee}${n.url}`}`
- `url` 必须**已经带 `?`**：后台下载按钮会拼 `` `${url}&download=1` ``。
- 该直链是**免登录**的（会被 `<img src>` / `<iframe src>` / DocumentServer 直接 GET，
  带不上 Authorization 头）。token 本身就是凭证 → 服务端只对「带 token 的 downloadConversationFile」放行匿名访问。
  证据：`AdminUserDetailDialog-D3FjH6JN.js` 的 `download()`：`p(`${await xa(e,t)}&download=1`)`

### 下载响应

必须带 `content-disposition`，前端据此判定「这是文件，不是 JSON」。
中文文件名按 RFC 5987 双写：`attachment; filename="中文_"; filename*=UTF-8''%E4%B8%AD%E6%96%87`

### Office 会话

```jsonc
{
  "session": {
    "serverUrl": "https://docs.example.com",   // 前端 `${serverUrl}/web-apps/apps/api/documents/api.js`
    "config": {
      "documentType": "word|cell|slide|pdf",
      "document": { "key": "...", "title": "...", "url": "...", "fileType": "docx",
                    "permissions": { "edit": true, "download": true, ... } },
      "editorConfig": {
        "mode": "edit|view",        // ← React key 里用到
        "lang": "zh-CN",
        "user": { "id": "...", "name": "..." },
        "customization": { "uiTheme": "theme-dark|theme-light", ... }
      }
    }
  }
}
```

- 消费方式（`ChatTeamUsage-CqW9fk-p.js`）：
  `function rh({session:e}){ let {serverUrl:c, config:l}=e; nh(c).then(a=>new a.DocEditor(id,{...l,events:{...}})) }`
  → **只解构 `serverUrl` 与 `config`**，其余字段前端不读。
- React key = `` `${config.editorConfig.mode}:${config.document.key}:${lang}:${theme}` ``，
  所以 `mode` 和 `document.key` 必须存在，否则 key 变成 `undefined:undefined:...`。
- `document.key` 要随**内容**变化（用 size+mtime 指纹），否则 DocumentServer 命中旧缓存。
- 本地复刻的 `serverUrl` 是 `/office-docs`，由 `server/lib/office-stub.mjs` 提供一个
  只读预览版 DocsAPI 替身；设 `CLAWSGO_ONLYOFFICE_URL` 指向自建 DocumentServer 即可换成真编辑器。

## 6. 计费：单位与公式

**一切金额都用「分」（cent）**，前端 `te(e) = `$${(e/100).toFixed(2)}``。
额度（credit）用 `milli`：1 credit = 1000 milli（`UNIT = 1e3`）。

### 月付与年付

证据：`app/assets/billing-D3pmhdeW.js`

```js
var z = 6e3;                                    // 年付系数，单位 1e-4 → 0.6（六折）
function B(plan, months) {
  return months === 12 ? Math.round(l[plan] * 12 * z / 1e4) : l[plan] * months;
}
var l = { free: 0, plus: 990, pro: 2990, ultra: 9990, team: 29990, enterprise: 99900 };
```

| 套餐 | 月付（分） | 年付（分） | 年付（元） | 折合 |
| --- | --- | --- | --- | --- |
| free | 0 | 0 | ¥0 | — |
| plus | 990 | 7128 | ¥71.28 | 7.2 个月 |
| pro | 2990 | **21528** | ¥215.28 | 7.2 个月 |
| ultra | 9990 | 71928 | ¥719.28 | 7.2 个月 |
| team | 29990 | 215928 | ¥2159.28 | 7.2 个月 |
| enterprise | 99900 | 719280 | ¥7192.80 | 7.2 个月 |

> 年付 = `round(monthly × 12 × 0.6)`，等价于「付 7.2 个月用 12 个月」。
> 曾经按 `× 6 / 10` 算成 17940 是错的，差额来自 `round` 的位置。

### 充值档赠送

```js
[[10,500],[50,1e3],[100,1500],[500,2e3],[1e3,3e3]].map(([e,t])=>{
  let r = e * 100;              // 元 → 分
  let i = n(r);                 // 基础额度（milli）
  return { priceCents: r, bonusBp: t, creditMilli: i, bonusMilli: i * t / 1e4 };
})
```

例：¥50 档 `bonusBp=1000`（+10%）→ 基础 5000 credit，赠送 500 credit，共 5500。

### 推广分佣

证据：`app/assets/promoters-BHsPDXsE.js`（页头文案「前 3 个月 × 30%」）

- 计佣基数：被邀请人**已支付订单**的 `amountCents`
- 计佣范围：每人**前 3 笔**（`PROMOTER_MONTHS = 3`）
- 比例：`3000` bp = 30%（`PROMOTER_RATE_BP`）
- 应结 = Σ佣金 − Σ已登记打款

## 7. 后台报表字段（前端逐字读取）

### `adminGetInviteCodeReport`

入参：`{ q?, sort: 'invited'|'revenue'|'lastInvited', limit, offset }`
返回：`{ codes: [...], total }`

| 字段 | 说明 |
| --- | --- |
| `codeId` / `code` / `isDefault` / `title` | 码本身 |
| `ownerId` / `ownerName` | 码主 |
| `invited` | 邀请成功人数 |
| `activated` | 其中真用过产品的（有消息） |
| `payers` | 其中付过费的 |
| `revenueCnyFen` / `revenueUsdCents` | 双币种收入 |
| `lastInvitedAt` | 最近一次邀请时间 |

### `adminGetPromoters`

入参：`{ limit, offset }` → `{ promoters, total, currency }`

表格列读取：`displayName` / `phoneNumber` / `since` / `invitees` /
`settleableCommission` / `currentCommission` / `settledAmount`
详情弹窗读取：`userId` / `dueAmount`（`dueAmount / 100` 显示为元）

### `adminGetPromoterDetail`

入参：`{ userId }` → `{ promotion }`

```jsonc
{ "promotion": {
    "currency": "cny", "rateBp": 3000, "monthsCount": 3,
    "months":      [ { "month": "2026-09", "base": 2990, "commission": 897 } ],
    "settlements": [ { "id": "...", "period": "2026-09", "amount": 100, "note": "...", "createdAt": "..." } ],
    "dueAmount": 897
} }
```

### `adminSettlePromoter`

入参：`{ userId, period, amount, note }`（`amount` 由前端 `Math.round(输入元 × 100)` 得到）

## 8. 主机

- `getHostDirectories` → `{ exists, path, parent, entries, directories, items, total, workdir, home }`
  - 每个 entry：`{ name, filename, path, type:'dir'|'file', kind, size, mtime }`
  - `directories` 是 `entries` 里 type=dir 的子集（前端用哪个都行）
- `createHostDirectory` → `{ ok, created, existed, path }`
  - **幂等**：同名目录再建一次返回 `created:false` 而不是 409，
    对齐 `mkdir -p` 语义（否则「新建文件夹」按钮重试会报错，e2e 也不可重复运行）
- `getHostStorage` → `{ storage: { usedGb, totalGb, ... } }`
- `getHostEnvironment` → `{ environment: { python, packages: [...] } }`

## 9. 空成功约定

未注册的命令在**登录态下返回结构化错误**（501 `NOT_IMPLEMENTED`），而不是 500 崩溃；
前端对未知命令的容错是「不整页报错」。静态资源缺失则必须老实返回 404 ——
把缺资源吞成 index.html 会让浏览器报 `Unexpected token '<'`，非常难查。
