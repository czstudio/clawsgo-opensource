## 二、novix 实现架构（当日公开产物直接分析）

### 2.1 技术栈 —— CONFIRMED [B]

**Next.js 营销壳 + Vite 构建 Vue 3 SPA**（混合架构，与 clawsgo 全 React 不同）：
- 落地页 Next.js（`_next/`、8843B HTML）；产品端 `/static/js/*`：`vue-vendor` + `antd-vendor`（**Ant Design Vue**）+ `i18n-vendor` + `lodash-vendor` + `index-Dk9cCEgm.js`（1.44MB 主包）

### 2.2 SSE 协议 —— CONFIRMED [B]（index-Dk9cCEgm.js 字节证据）

- **GET + `Accept: text/event-stream` + `Authorization: Bearer` 双头**（@163356）——与 clawsgo 的 POST SSE 不同
- **帧以空格分帧**：`g.split(' ')` 逐帧解（@163683），终止哨兵 **`event:complete`**（@163700 附近）
- 状态面（Pinia）：`sseEventSource / chatBoxLock / pendingSessionLaunch / initSession{isNewSession,hadExplicitAgent} / enableGpu` —— 会话启动前有显式 agent 选择与 GPU 开关

### 2.3 功能面 —— CONFIRMED [B]

- 端点：`/api/chat/`、`{prefix}/file/upload_stream`（流式上传，FormData+Axios）
- 智能体模式含示例任务卡（如 `ML Agent / Auto Experiment`：稀疏自编码器可解释性任务描述，即模式注册表带预置任务）

- 登录态功能（Canvas 子智能体、审批卡实时流、Auto-Discovery File Space 实操）——需要 novix 账号会话；本轮只打公开面。方法已有先例（10-08 车道的独立 profile 复制法），需要时按同一方法补测。
